# 15: 翻译动态新增内容

**What to build:** 页面翻译会话保持开启时，自动处理后续加载和无限滚动新增的英文内容；未变化的已有内容不会重复提交，恢复原文后停止处理新增内容。

**Blocked by:** 14: 完成可翻译内容识别与格式保护

**Status:** ready-for-human

- [x] 会话开启期间能够发现新增正文和界面文本，并按现有语言与代码保护规则建立翻译单元。
- [x] 新增英文内容通过当前页面翻译会话和相同配置快照提交，不启动相互冲突的新会话。
- [x] 已翻译且原文未变化的已有内容不会因其他节点新增而重复提交。
- [x] 新增内容命中译文缓存时可以直接渲染，未命中时才进入翻译请求流程。
- [x] 无限滚动或分批加载时，成功译文逐批显示，页面阅读顺序不由响应顺序决定。
- [x] 插件插入译文具有基础防重入处理，不会因自身 DOM 变化持续制造新翻译单元。
- [x] 恢复原文后停止监听和处理新增内容，之后出现的新节点保持原始状态。
- [x] 页面移除节点后，相关过期结果不会渲染到无关位置。
- [x] 使用动态样本覆盖追加、无限滚动、缓存命中、重复观察、恢复后新增和过期响应。

## Comments

### 2026-11-17 实现完成

- 实现：会话开启 MutationObserver（childList + characterData，防抖 200ms），扫描新增正文与界面文本；未变化单元按注册表跳过；插件自身写入通过 `runOwnMutation`（微任务内抑制）与自身节点过滤忽略，避免自我触发。
- 新增内容复用当前会话与已固定的配置快照，不启动新会话；节点移除时清理对应译文，迟到结果因注册表查不到而被丢弃。
- 译文缓存由 Translation Engine Implementation 隐藏（ticket 08）；缓存命中与网络返回走同一条渲染路径，Session 不假设缓存策略。
- 验收：`tests/unit/page-translation-session.test.ts`（动态新增正文、动态新增界面文本、未变化不重复提交、节点移除清理、恢复后停止处理）；`tests/e2e/page-translation.spec.ts`（动态页新增段落自动出现译文）。
