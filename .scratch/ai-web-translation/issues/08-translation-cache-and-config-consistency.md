# 08: 加入译文缓存与配置一致性

**What to build:** 将成功译文保存在本机，使重复内容在相同翻译配置下无需再次请求，同时确保缓存不会跨配置混用。页面翻译会话在首次请求时固定配置快照，后续设置修改不会改变当前会话。

**Blocked by:** 07: 支持长选区分批、翻译上下文与部分结果

**Status:** ready-for-agent

- [ ] 相同规范化原文在相同源语言、目标语言、翻译服务、模型、翻译提示词和影响结果的请求参数下可以直接复用成功译文。
- [ ] 缓存键不包含 API Key，不同翻译服务、模型、提示词或有效请求参数不会混用译文。
- [ ] 重复划词命中缓存时不会产生翻译服务请求，扩展重新加载后缓存仍可按设计使用。
- [ ] 只有成功且通过单元 ID 校验的译文可以写入缓存，失败、取消或无效响应不会污染缓存。
- [ ] 用户可以清空译文缓存，清空操作不会删除翻译服务配置、自动翻译网站或悬浮按钮站点停用设置。
- [ ] 页面翻译会话首次请求时固定配置快照，同一会话后续批次和新增内容继续使用该快照。
- [ ] 修改默认配置或编辑配置不会影响已经开始的会话；新会话才能使用最新配置。
- [ ] 配置变化后，相同原文不会因为旧缓存而绕过新配置应有的翻译行为。
- [ ] 测试通过 Translation Engine Interface 覆盖缓存命中、配置隔离、重新加载、清空、失败不写入和会话快照。
