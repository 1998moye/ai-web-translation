# 18: 支持按网站自动翻译

**What to build:** 用户可以为当前完整域名开启或关闭自动翻译，并在设置页管理自动翻译网站。打开已启用网站时，只有检测到英文内容才自动创建页面翻译会话。

**Blocked by:** 17: 完成页面会话控制

**Status:** ready-for-human

- [x] 用户可以从悬浮按钮相关设置或扩展设置页为当前完整域名开启自动翻译。
- [x] 自动翻译偏好在扩展重新加载后保持，并可以在设置页查看、逐个移除或关闭。
- [x] docs.example.com 的自动翻译设置不会影响 example.com 或其他子域。
- [x] 打开已启用网站时，只有识别到需要翻译的英文内容才自动创建页面翻译会话。
- [x] 非英文网站、已有中文网站或没有可翻译英文内容的页面不会自动产生翻译请求。
- [x] 自动翻译与手动翻译共用 Page Translation Session，不会创建重复会话或重复翻译单元。
- [x] 用户恢复原文或取消后，同一次页面停留不会被自动逻辑立即强制重新翻译。
- [x] 自动翻译网站列表与悬浮按钮站点停用列表分别保存和管理，互不误删。
- [x] 测试覆盖完整域名隔离、英文与非英文页面、持久化、网站管理、手动优先和恢复后不重复自动触发。
