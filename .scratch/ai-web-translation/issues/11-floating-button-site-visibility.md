# 11: 完成悬浮按钮关闭与网站停用管理

**What to build:** 用户可以从悬浮按钮的展开入口关闭当前页面的一次显示，或按完整域名持久停用悬浮翻译按钮，并在设置页查看和移除这些网站。

**Blocked by:** 10: 显示可拖动的悬浮翻译按钮

**Status:** ready-for-human

- [x] 悬停悬浮翻译按钮后可以展开关闭入口，并清楚区分“关闭一次”和“此网站永久关闭”。
- [x] 关闭一次只隐藏当前页面中的按钮，不写入持久网站停用记录，刷新或重新打开页面后恢复。
- [x] 永久关闭按当前完整域名保存，扩展重新加载和页面重新打开后仍然隐藏。
- [x] 停用 docs.example.com 不会影响 example.com 或其他子域。
- [x] 设置页可以查看全部悬浮按钮站点停用记录，并允许逐个移除。
- [x] 移除记录后，对应网站在下次打开或刷新时恢复悬浮翻译按钮。
- [x] 永久关闭不会误删翻译服务配置、译文缓存或自动翻译网站偏好。
- [x] 悬浮按钮站点停用与自动翻译网站列表分别管理，不将隐藏按钮等同于禁用全部翻译。
- [x] 测试覆盖单次隐藏、刷新恢复、完整域名隔离、持久化、移除记录和设置变更后的页面行为。
