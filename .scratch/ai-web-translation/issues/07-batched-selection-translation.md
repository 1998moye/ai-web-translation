# 07: 支持长选区分批、翻译上下文与部分结果

**What to build:** 长选区通过 Translation Engine 拆分为翻译单元和翻译批次，并利用只读翻译上下文改善质量。成功批次可以先显示，任何响应都必须通过严格的单元 ID 校验，避免译文错位。

**Blocked by:** 06: 支持划词切换配置与内容保护

**Status:** ready-for-agent

- [ ] 长选区会生成具有稳定 ID 的翻译单元，短文本适当合批，长文本按合理段落或长度拆分，不把整个长选区作为唯一不可拆分请求。
- [ ] 正文翻译可携带页面标题、当前小节标题和前一段原文作为翻译上下文，上下文只用于理解且不要求返回译文。
- [ ] 短界面文本不会被强制附加无关上下文。
- [ ] 请求和响应通过单元 ID 对应，缺失、重复、未知或无法解析的 ID 不会被猜测性渲染。
- [ ] 成功批次可以先显示，失败批次保留对应英文并显示可识别的失败状态，不回滚其他成功内容。
- [ ] 批次乱序返回时，译文仍按原选区顺序呈现，不由网络返回顺序决定阅读顺序。
- [ ] 当前会话中的多个批次使用相同翻译服务配置和翻译提示词。
- [ ] 测试覆盖多批成功、部分失败、乱序、重复 ID、缺失 ID、未知 ID、无效结构和上下文不被翻译。
- [ ] 长选区气泡在长文本和部分失败情况下仍可读，不出现无法分辨的原文与译文对应关系。
