# 默认在所有普通网站显示悬浮翻译按钮

用户要求悬浮翻译按钮在普通网站打开时即可使用，不经过扩展内逐站授权，因此首版接受所有 HTTP/HTTPS 网站的广泛主机权限，而不是只通过 activeTab 按需注入。这一选择用更直接的交互换取更大的权限范围和潜在商店审核成本。

## Consequences

- 设置页必须清楚说明权限用途，浏览器自身的权限提示不能被描述为“不存在授权”。
- 浏览器内部页、扩展商店和其他受限页面仍不保证注入。
- 展示悬浮按钮本身不发送网页文本；只有手动翻译或用户开启网站自动翻译后才向所选翻译服务发送内容。
- 若未来改为按网站授权，未授权网站将无法默认显示悬浮按钮，需要重新设计首次启动交互。
