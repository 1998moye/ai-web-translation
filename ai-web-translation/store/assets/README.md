# 商店图形素材

- `npm run store:assets` 生成图标、商店 Logo 与宣传图。
- `npm run store:screenshots` 生成 1280×800 的商店截图。

文件：

- `icon-128.png`：Chrome Web Store 图标
- `icon-300.png`：Edge Add-ons 商店 Logo
- `promo-small-440x280.png`：Chrome / Edge 小型宣传图
- `promo-large-1400x560.png`：Chrome / Edge 大型宣传图
- `screenshots/`：3 张 1280×800 商店截图
