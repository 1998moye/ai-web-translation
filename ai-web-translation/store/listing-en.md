## Name

`AI Web Translator · English to Chinese`

> The Chrome Web Store item name must match the manifest name. Use the Chinese manifest name as the primary listing name and add this English description as a localized listing if the dashboard allows a localized name; otherwise keep the name field as `AI 网页翻译 · 英文转中文`.

## Short description

`Translate English pages into Chinese with your own OpenAI-compatible AI service. Bilingual pages, selection translation, no built-in model.`

## Detailed description

```text
Translate English web pages into Chinese — with an AI service you already trust.

This extension only translates English into Chinese. It does not ship with a built-in model or a shared API key. Add your own OpenAI-compatible Chat Completions endpoint, model, and API key in Settings; you pay your provider directly.

FEATURES
• Whole-page bilingual reading: keep the English original and show a Chinese translation below each paragraph.
• Selection translation: select an English sentence and click the small icon to see a Chinese translation.
• Interface text: navigation, buttons, and form labels are translated in place, with the English original available on hover.
• Dynamic pages: newly added content and changed source text are handled automatically.
• Multiple profiles: save separate endpoints/models and switch the default at any time.
• Editable prompt, translation cache, concurrency/timeout/retry settings.
• Per-site auto-translation and a permanent floating-button block list.
• Keyboard accessible, dark mode, and reduced-motion support.

HOW TO USE
1. Install the extension and open Settings → Translation service.
2. Create a profile with a complete OpenAI-compatible Chat Completions URL, model, and API key.
3. Open any English page and click the floating button to translate the page; select text for a quick translation.
4. Click the floating button again to restore the original page.

IMPORTANT
• English → Chinese only. Chinese → English and other language pairs are intentionally unsupported.
• No built-in model, free quota, or shared API key. You must configure your own AI service.
• Translation requests go directly to the endpoint you configure, not to the extension developer.
• API keys, profiles, and cached translations stay in local extension storage.

PRIVACY AND PERMISSIONS
The extension needs permission to read and change data on the sites you visit so it can show the floating button on any ordinary page and read English text only after you click translate or enable auto-translation for that site. Protected pages such as browser internal pages and extension stores are not injected. No analytics, ads, or telemetry. Full details are in the privacy policy.

```
